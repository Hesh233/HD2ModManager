# Arsenal 物理外置包平铺导出（2026-11-10）

已由用户验收：原 VRD 1.3.1 / runtime 2.3.1 物理载荷正常；B3 基础运行时和开关面板现用两包保留。

## 修复

Arsenal 0.37.1 对所选 Include 目录只读取直接文件。旧物理分发目录下的 `patch版/` 多一层，可能显示已部署却复制 0 文件。

- 物理功能现在在其功能目录根生成 `manifest.json` 与 patch 三件套，没有重复的嵌套 patch。
- `lua版/` 仅保留可编辑源码，选择一种加载方式，不同时加载两份物理。
- 已有导出缓存即使 Lua 内容没变，也会检查布局；旧布局缺根 manifest/三件套时刷新。
- 原生骨架工程的物理补丁重编号从新的功能根目录取文件。
- 其它挂点/外观功能原有布局保持，不顺带推广 B3 测试候选或暂停的布娃娃研究。

## 已验证

- 新布局覆盖根 manifest、单一 patch 三件套、ZIP 根/单功能外层、旧目录重导、固定 addon ID 和其它功能兼容。
- Core 回归：1131 通过、1 既有真实模型素材缺失跳过；另 1 既有挂点日志字符串断言不符合安装基线，单独记录，不包装成全套通过。
- 固定管理器定向更新 Core/GUI 两个 DLL：仅各两个打包相关方法变化；方法数量、常量、引用与嵌入资源保持。
- 所有 31 个已安装 Core 嵌入资源均冻结到原字节，包括 physical、grip、其它运行时；实际安装后导出与已验收物理 manifest/三件套逐字节一致。
- 不修改配置、模组库、模型/动画、游戏部署，不重导或重烘；原 B3/物理 ZIP 保持。

## 使用

重启固定 manager-1.0.7，重新导出物理功能目录即可得到平铺布局。导入 Arsenal 后启用 `HD2 物理骨骼运行时`，停用旧外层条目，重新部署并完全重启游戏。不要只看“已部署”标签，应核对新 Chef 模块清单与物理日志会话时间。

物理算法仍为已接受的 compat 1.3.1 / runtime 2.3.1。不是增加 A3 末尾桥，也不是所有动作/FPS 的新穷尽验收。性能反馈不视为精确 FPS 基准。
