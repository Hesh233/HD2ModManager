# Skeleton animation prompt regression

This tool loads the actual GUI assembly with each installation's preserved dependency baseline.

- `audit <before-program> <candidate> <report.json>`: symbolic IL/reference audit, settings-only BAML resource diff and portable PDB identity check.
- `headless <candidate> <output> <accepted-anim_batch_mod>`: defaults, settings persistence/cancellation, real route/thread policies and actual settings-card TwoWay binding/render tests. Does not create a Window, call Show/ShowDialog, start Python, import a library, or deploy a game.
- `verify ...`: optional modal-dialog suite; requires explicit desktop/GUI execution permission. Do not use this as a fallback after an approval rejection.

Settings tests require a fresh executable directory with `SMOKE-SANDBOX.marker`; the installation's settings/configuration are never used as the test write location. Keep failed sandboxes as evidence and use a fresh directory on retry.

The import-options cases verify default-hidden dual routes, actual UI default buttons, skeleton-only 0.9–1.1 warnings (No keeps input, Yes keeps the exact scale), and injected production step order route→scale→armor→threads before conversion. Record handoff and absence of the late armor prompt are checked against the actual candidate assembly. Preview rendering uses a white in-memory surface, never a native Window.
